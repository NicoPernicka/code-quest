Das HTML-Grundgerüst

Das Zuhause deiner Webseite

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <title>Meine Seite</title>
</head>
<body>
  <h1>Hallo Welt!</h1>
  <p>Meine erste Webseite.</p>
</body>
</html>

Merke: Im <body> steht der sichtbare Inhalt. Die meisten Tags haben einen Start- und einen End-Tag.

✍️

Überschriften & Texte

Worte auf die Seite bringen

<h1>Große Überschrift</h1>
<h2>Kleinere Überschrift</h2>
<p>Ein Absatz mit Text.</p>
<strong>Wichtig!</strong>
<em>Betont!</em>
Zeile eins<br>Zeile zwei

<h1> ist die wichtigste Überschrift. <p> steht für einen Absatz. <br> macht einen Zeilenumbruch.

🖼️

Buttons, Bilder & Listen

Mehr als nur Text

<button>Klick mich!</button>
<a href="https://example.com">
  Ein Link
</a>
<img src="katze.jpg"
     alt="Eine Katze">
<ul>
  <li>Pizza</li>
  <li>Pasta</li>
</ul>

Das alt-Attribut beschreibt ein Bild. Listenpunkte stehen in <li>; <ul> erstellt eine Liste mit Aufzählungspunkten.

🌈

Farben & Schrift

Mach es zu deinem Style

body {
  background-color: lightblue;
  font-family: Arial, sans-serif;
}

h1 {
  color: purple;
  text-align: center;
}

p {
  font-size: 20px;
}

CSS-Regeln folgen dem Muster Eigenschaft: Wert;. Die geschweiften Klammern gruppieren die Regeln für ein Element.

redbluegreenorangepinkpurple
📐

Abstände & Formen

Alles an seinen Platz

.karte {
  background-color: white;
  border: 2px solid blue;
  border-radius: 15px;
  margin: 20px;
  padding: 10px;
  width: 200px;
}

Margin ist Abstand außen. Padding ist Abstand innen. Border-radius macht Ecken rund.

🪄

Klassen & Buttons

Elemente gezielt stylen

/* HTML: <button class="cool">Los!</button> */
.cool {
  color: white;
  background-color: purple;
  border: none;
  border-radius: 12px;
  padding: 12px 18px;
  cursor: pointer;
}

.cool:hover {
  background-color: blue;
}

Eine Klasse beginnt im CSS mit einem Punkt: .cool. Mit :hover kannst du den Stil ändern, wenn die Maus darüber ist.

📦

Variablen & Nachrichten

Informationen speichern

let punkte = 0;
const lieblingstier = "Katze";

punkte = punkte + 1;

console.log(punkte);
alert("Hallo, Welt!");

let erstellt eine veränderbare Variable. const verhindert eine neue Zuweisung. Texte stehen in Anführungszeichen, Zahlen nicht.

🤔

Bedingungen: Wenn … dann …

Der Computer entscheidet

let punkte = 12;

if (punkte >= 10) {
  console.log("Gewonnen!");
} else {
  console.log("Weiter üben!");
}

if prüft, ob etwas stimmt. Falls nicht, kann else einen anderen Weg ausführen.

=== gleich!== ungleich> größer< kleiner>= mindestens

Funktionen

Deine eigenen Befehle

function sagHallo() {
  alert("Toll gemacht!");
}

// Funktion starten:
sagHallo();

Eine Funktion bündelt Befehle, die du wiederverwenden kannst. Mit ihrem Namen und runden Klammern rufst du sie auf.

🖱️

Klicks & Webseiten ändern

Mach die Seite interaktiv

<p id="ausgabe">Hallo!</p>
<button onclick="wechseln()">
  Klick mich
</button>

<script>
function wechseln() {
  document.getElementById("ausgabe")
    .textContent = "Du hast geklickt!";
}
</script>

onclick startet etwas beim Klicken. getElementById findet ein Element anhand seiner ID. textContent ändert seinen Text.

Keine Treffer gefunden. Versuch einen anderen Suchbegriff. 🔎
